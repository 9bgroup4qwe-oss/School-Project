## 🎯 Project Summary

**Learn.ai** is an AI-powered educational platform that:
- Helps students study for exams using personalized AI assistance
- Supports NCERT curriculum for Indian students (Classes 6-12)
- Provides study planning, progress tracking, and AI-generated quizzes
- Offers both Google OAuth and email/password authentication
- Includes features like textbook scanning, adaptive learning, and performance analytics
