# Designs Directory

This directory is for uploading website page designs that the UI-designer MCP can reference for implementation.

## Structure
- `pages/` - Upload individual page designs here (screenshots, wireframes, mockups)
- Support formats: PNG, JPG, PDF, Figma links

## How to Use
1. Upload your page design files to the appropriate subdirectory
2. The UI-designer MCP will reference these files when implementing the UI
3. Name files descriptively (e.g., `homepage-hero-section.png`, `dashboard-analytics.png`)

## Naming Convention
- Use lowercase with hyphens
- Include page name and section in filename
- Example: `quiz-question-card.png`, `study-planner-calendar.png`
